# Third-party notices

`pveforge` compiles to a statically linked Go binary that contains code from
the third-party modules listed below, in addition to pveforge's own source.
Those modules' licenses apply to that code wherever it goes.

**What this file does and does not cover.** Apache-2.0 section 4(d) accepts
attribution in any of three places: a `NOTICE` file distributed *with* the
derivative work, the documentation supplied alongside it, or a display
generated by the work itself. A markdown file in the source repository
satisfies the second of those for *source* distribution — which is how
pveforge is distributed today, and so this file is sufficient as things
stand. It satisfies none of the three for a compiled binary handed to
someone who does not also have this repository.

If pveforge ever ships binaries — a release artifact, a container image, an
OS package — this file alone stops being enough. Such a distribution would
need to carry the notices with it: ship this file (or a generated `NOTICE`)
alongside the artifact, or have the binary print them on request. Neither
mechanism exists yet, and adding one is a prerequisite for the first binary
release, not an afterthought.

pveforge's own license is unchanged and is stated in [`LICENSE`](LICENSE):
dual MIT or Apache-2.0, at your option. Nothing here narrows it.

This file lists the modules linked into `cmd/pveforge`, as reported by
`go list -deps ./cmd/pveforge` for linux, darwin, windows and freebsd on amd64
and arm64 (one module is linked on Windows only, and says so). It does not
list build- or test-only dependencies, which are not distributed. The module
guard (`internal/sourceguard`) fails while this table and those modules, or
their versions in `go.mod`, disagree.

## Apache-2.0 attribution

Three linked modules are Apache-2.0 licensed: `github.com/spf13/cobra`,
`github.com/inconshreveable/mousetrap` (Windows builds only) and
`github.com/suykerbuyk/go-proxmox`. Section 4(d) requires that any `NOTICE`
file they carry be reproduced in the derivative work's own notices, subject
to the placement caveat above.

`github.com/spf13/cobra` and `github.com/inconshreveable/mousetrap` ship no
`NOTICE` file.

`github.com/suykerbuyk/go-proxmox` does, and it is reproduced verbatim below.
Note that this module is pveforge's own fork of an upstream project: the
copyright in the bulk of that code belongs to the upstream authors, not to
us, and this notice is how that stays visible in pveforge's distributed
source.

## A note on the go-proxmox fork

pveforge depends on `github.com/suykerbuyk/go-proxmox`, which is a fork of
[`github.com/luthermonson/go-proxmox`](https://github.com/luthermonson/go-proxmox).
Upstream is the canonical project and remains the right choice for anyone who
does not specifically need this fork. The fork's own `CHANGES` file records
every modification made to it, as Apache-2.0 section 4(b) requires.
